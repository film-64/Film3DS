# Gref条件参考EI估算

可以从现有数据估算参考EI；它不同于已完成绝对ISO标定。没有新增采集。

对象：Sensor1、15fps、固定增益Gr/B/R/Gb = 0220/024A/0225/0220，数字1×。

操作性输出判据：中心处理后Y中位数118。它是本次明确选定的参考输出点，不是声称手机或富士已拍到同一块标准灰。

已有积分扫描：coarse64时中心Y75.40；coarse176时Y131.66。用行周期模型换算粗积分时间，并在这两个实测点之间插值到Y118。

|插值假设|达到Y118的时间估值|用手机1/25参考计算EI|用手机1/30参考计算EI|
|---|---:|---:|---:|
|linear_output_y|14.091ms|283.9|236.6|
|linear_y_vs_log_time|13.036ms|306.8|255.7|
|assumed_gamma_2_2_linearization|13.452ms|297.4|247.8|

**条件估计约EI240–310；这是所列参考与插值模型的包络，不是统计置信区间，也不是已实测ISO范围。**

当3DS与测光输入光圈同为名义f/2.8，公式简化为 EI = 100 × t_ref / t_3DS_to_reference_output。两边光圈不同时还需乘以(N_3DS/N_ref)^2。

真正缺口是曝光匹配：固定增益的3DS哪一档积分达到约定参考输出，以及该图像与手机测光是否确属同一照明/测光区域。已有旧曲线跨过Y118，所以可以先插值，不必为出这个条件估值重采。新EV10批次只扫固定coarse7，中心Y9–56，不能与旧EV7.6批次直接拼接为新的绝对标定。

保留条件：旧手机读数与旧积分扫描照明一致、测光区域足够匹配；采用3DS名义f/2.8；允许用Y118定义参考渲染亮度；时间采用粗积分行周期模型且尚未校正fine；插值仅近似实际曲线。上述不确定性未被本模型包络穷尽。

因此固定感光档已有控制值，参考EI也能先给条件估计。精确ISO仍需确认曝光匹配与时序精度，而不是继续增加同类寄存器扫描或要求用户另提供一个ISO数字。
