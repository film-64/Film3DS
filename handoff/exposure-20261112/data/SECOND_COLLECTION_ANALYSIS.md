## 1. 旧增益倍率公式不能直接使用

新EV10批次固定coarse=7、数字倍率1、四通道相同原始代码。六个点及恢复全部通过，14阶段/168正式帧。

|输入四通道代码|底层302A代码|中心Y中位数|处理后Y时间噪声σ|
|---|---:|---:|---:|
|0x0210|4|9.133|0.548|
|0x0218|6|18.160|0.956|
|0x0220|8|25.961|1.235|
|0x0228|10|37.288|0.964|
|0x0230|12|45.710|1.037|
|0x023C|14|56.226|0.957|

这是输入代码到实际底层代码和渲染结果的实测表，不是ISO表。0x023C读到底层14，不能依据之前公式把它认定为精确1.875×。此前名义2×代码0x0240虽保持，但底层绿色代码为0、画面反而变暗；名义4×蓝通道要求03CF、实际02CF。必须纠正编码模型，不能据旧公式推断硬件最高ISO。

仍有光度稳定性限制：首个短曝光基准在12帧中的中心Y跨度约14.07（中位30.21）；相同0x0220目标与前后恢复也有亮度差。寄存器保持不等于场景或全部ISP处理稳定。上述噪声是处理后Y的波动，不能当作RAW读噪声、电子数或绝对感光度。

## 2. 数字倍率有效，但需要保留高亮余量

独立数字段72正式帧完整，模拟控制和积分保持；3032从256变512、1024并恢复。中心Y中位数约163.47→221.99→252.07。最后一张2×样本约7.9%中心像素≥235，但无255像素；4×约4.28%中心像素为255。高亮阈值和真正输出端点不能混用。准备的digital-headroom尚未部署，不把缺失对照算作已完成。

## 3. 快门必须结合帧长分析

实测DMA间隔：30fps组约33.286ms，15fps约66.667ms，5fps约199.952ms；对应frame_lines约518、704、2114。15与5fps组同类PLL/行长下，相同coarse会产生相近响应，支持积分代码具有可控时长含义。

已验证普通积分点：30fps为1/4/16/64/129/388，15fps为1/4/16/64/176/528，5fps为1/4/16/64/528/1585。代码1在当前场景为黑，5fps的1585中心到255；这两端都不能直接作为可用摄影档位。

最大16位值不能直接变成最慢快门：FFFF原始回包为FFFF，但原驱动0x0010A64C–65A将该值视为错误哨兵；FFFE独立实验可读回65534，却在固定30fps下等30002ms仍无帧。后者还触发超时后的其他增益变化，严格恢复验证拒绝，不能继续冒充稳定长曝。

数据要求下一步显式联动frame_length_lines与coarse，比较正常取帧、控制保持和等待时间。当前所有普通有效点最多约为所设帧长的四分之三；跳到65534没有同时建立合适帧长，因此其失败不等价于硬件不支持较慢曝光，更不能据此宣称无B门。即使采用行周期模型估算，也必须标为模型结果；fine偏移与真正光学曝光窗尚未单独验证。

## 4. ISO标定的条件与缺口

新测光批次：用户提供ISO100、f/2.8、1/125秒、EV10；由光圈/快门换算EV100约9.937，与EV10取整相符。早先两个App的参考约EV7.61/7.88；用户已明确环境变化，跨批次不直接比较绝对亮度或噪声。

名义f/2.8来源：[3DS Programming Manual: System v1.6公开镜像，2.8.5 Cameras](https://pdfcoffee.com/3ds-programming-manual-pdf-free.html)。文档署名任天堂但并非官方原站，模块适用性、透光率未实测。它提供了候选光圈基准，尚不把ISO与光圈两个未知数同时反求。

下一步可建立明确条件下的参考曝光指数EI：校正实际增益代码，验证曝光时间，把同一照明/取景/固定处理设置下的参考测光与规定的输出亮度相配。当前短积分点靠近黑端、旧批次积分点不同照明，不能拼接成可靠ISO100–400表。

## 5. 对应用逻辑的直接含义

首轮已经证明SetAutoExposure(false)后再SetExposure(0)，高层getter仍报告关闭，但MCU A11D从0变1。SetExposure不是独立快门，也不是ISO。现有随环境变化的曝光加减可以作为自动曝光补偿保留；真正固定增益模式必须直接控制实际增益，并让自动测光只调整积分。所有会重设相机模式/幀率/曝光目标的调用应先完成，再锁定、写入目标并核验，不能仅依赖getter。

本轮未修改主应用。连续预览锁定、A档软件测光与手动曝光状态机仍需在应用集成后独立验证，不能以逐帧停止/启动的探针结果替代。
