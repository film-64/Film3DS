# Roll 方塊列表與原始檔刪除

第一行為 `Photo 目前序號 / 原始檔總數`。其下使用每排 10 個位置的方塊列表，一屏最多三排。已存在的原始 F3S 用金色方塊表示，選中項以綠色外框標記；不足一排的空位為暗色且不可選。依實際檔案數增減排數，超過三排時隨選取位置捲動。沒有原始檔時顯示 `Photo 0 / 0` 和空列表，不混入虛擬照片。

左右一格，上下一排，支援方向鍵與搖桿的固定重複輸入。第一排向上、最後一排向下保持原位；下方一排不足十張時落在最後一張。觸控方塊只選取，不直接打開暗房。切換選取位置後即讀取該 F3S 並更新上屏預覽，沒有生成縮圖或新增相機調用。A 保留進暗房功能，原有 `A Open darkroom` 佔位提示已移除。X 保持換頁。

Y 打開刪除確認窗口，顯示選中 F3S 的確切檔名。只有單獨按 A 才刪除，X 取消。確認窗口攔截其他輸入，不觸發拍攝、換頁或暗房保存。刪除目標記錄 ID 及索引，執行前重新核對當前選取及列表，拒絕過期目標；拍攝寫檔進行中拒絕開始刪除。一次確認只允許一次嘗試，沒有自動重試。

只刪除該 `ROLLnnnn.F3S`，已輸出的 JPEG 保留。成功後移除列表項，優先選下一張；刪除最後一張時選前一張。清除暗房舊快取並更新上屏；全部刪完後清空照片預覽。檔案刪除失敗顯示錯誤並保留原列表。

## 契約、改動及驗證

- 分類：`film-roll-preview/v1` 為選中原始檔的本機讀取／像素預覽計算；`film-roll-delete/v1` 為明確確認的單一原始檔副作用。沒有排程器、LaneAdmission、覆寫理由、佇列或重試。
- `tools/camera_runtime_contract.py` 的 CONTRACT_MATRIX 已在實作前登記兩個來源與包裝規則；產生的來源表同步更新。verifier 僅加入已登記來源，未知來源仍 fail closed；沒有放寬驗證規則。
- 沒有新增 scheduler/runtime-internal 欄位，也沒有更動可攜式配方／F3S 格式。`FilmRoll` 是本機 UI 選取、捲動與刪除確認狀態，不進入影像配方。
- 新增 `include/roll.h`、`source/ui/roll.c` 和 `tests/roll.c`。原生 UI 僅修改 Roll 顯示、輸入、讀取和刪除接線；`tests/camera_ui_package.py` 新增來源契約檢查；Makefile 加入 Roll 測試。
