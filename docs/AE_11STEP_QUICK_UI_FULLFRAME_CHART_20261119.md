# Native AE ±5／簡潔拍攝 UI／全幅灰階測試（2026-11-19）

此版以 `minmain` 為基礎，只擴充**原生 CAMU 曝光補償等級**至 `−5..+5`，共 11 級；3DS 韌體原生等級不等同已測得的 EV，不能先假設相鄰級距必為 1/3 EV。先前 ±3 的低階手動感光增益保留獨立界限。既有 DNG、F3Y、F3E 和 SD 卡自裝 `.cube` LUT 均不覆寫。

## 拍攝首頁（不必打開設定選單）

- `十字鍵 ← / →`：Native AE 補償等級逐級減少／增加（限 −5..+5），畫面大字顯示已確認設定的 native level。手動模式則控制原有 −3..+3 步階。補償變更會**關閉、重開攝影機並從 Native 等級 0 初始化，再寫入唯一的目標級數**。若硬體 API 回錯，明示失敗與需重新按 L；不假裝檔位已生效。
- `十字鍵 ↑ / ↓`：將硬體測光框縮小／放大，依序 640×480、480×360、320×240、160×120、80×60。只在 Native AE、後置 REAR1、1×、相機已啟動時生效。
- `SELECT + 十字鍵`：移動已設定的**硬體**測光框（不是數位放大、沒有裁切影像）；`SELECT + Y`：全畫面與中央 320×240 切換。
- `Y`：展開精簡的三行進階項目：曝光模式、Native level、Manual step。打開時十字鍵上下切項、左右調數字；再按 `Y` 關閉。你仍可透過選單進入 Manual 模式。
- `A / R`：原有 DNG 快門；`SELECT + R`：額外保存配對 `DNG + F3Y v2 + F3E` 以供灰階分析。
- `L`：相機啟動／切換／關閉，`X`：切換 Film3DS 的 ROLL／DARKROOM 頁；搖桿維持既有縮放功能。

上屏繼續顯示可見取景畫面，綠框僅在 `CAMU_SetAutoExposureWindow` 返回成功後顯示；下屏只顯示目前等級、測光框尺寸、主要方向鍵操作與快門捷徑。界面不再佔用三大塊靜態按鈕區。

## 21 階無背景灰階圖

包含三種完全獨立的 PNG；**測試時請使用完整無邊框的版本**：

| 檔案 | 像素／方向 | 內容 |
| --- | --- | --- |
| `Film3DS-gray21-portrait-3x4.png` | 945×1260，3:4 直幅 | 原始直幅，21 條水平灰階色帶，每條恰好 60 像素高。 |
| `Film3DS-gray21-landscape-4x3.png` | 1260×945，4:3 橫幅 | 上述 3:4 圖**逆時針旋轉 90°**，對應 3DS 640×480 橫向取景。建議在一般橫向顯示器上使用這一張。 |
| `Film3DS-gray21.png` | 1680×920，舊版 | 帶有黑灰邊框與文字，故意保留作背景影響對照。 |

全幅版每個像素都屬於 21 個灰階之一，沒有文字、黑邊、圖例或假設性的光學校準參數。21 個色階依 `round(i × 255 / 20)` 取得 8-bit sRGB 中性碼 `R=G=B`，包含 0 和 255。**完整畫面中含有 0（純黑）色帶是測量對象的一部分，不是外部黑邊。**

注意：`3:4` 是**直式相片比例**，3DS 原生攝影感光元件與預覽是 `4:3` 橫幅。想讓灰階圖填滿 3DS 畫面，應打開預先旋轉好的 `landscape-4x3` 版本，或把直幅圖**實際轉 90°** 後取景。不要拍成直幅窄條＋大塊黑背景，否則本次對照目的會失效。

## 控制背景因素的最小對照

1. 固定螢幕亮度、相機位置、對焦距離、房間環境光；關閉自動亮度／HDR／夜間色溫／動態對比。兩種圖的灰階代碼必須完全一致。
2. **第一組：帶黑邊舊圖。** Native AE level 0、測光全畫面、1×，灰階色帶完整居中，拍 3 組 `SELECT+R`。記錄灰階實際佔取景面積。
3. **第二組：無黑邊全幅圖。** 相機位置、屏幕亮度、Native AE level 0、測光全畫面保持一致，讓無邊框 4:3 灰階圖**盡可能填滿整個 640×480 取景畫面**，拍 3 組。灰階圖可用螢幕圖片檢視器調整顯示以匹配，但不能讓黑邊／視窗控制項進入取景。若因縮放影像而改變色彩內插，記錄這件事。
4. **第三組：無黑邊全幅圖＋中央 320×240 測光。** 只調測光框，不移相機／螢幕；在 Native AE level 0 再拍 3 組。
5. 若關心端點補償可額外於第三組做 `−5,0,+5` 各至少 2 組，但**+5 若造成 RAW 飽和，該白階不適合作 EV 校準**。

必須分開分析：`F3Y` 原生顯示影像的 8-bit 剪切、DNG RAW10 的飽和／實際光比，以及外部黑背景佔取景面積。保持灰階中心 ROI 一致後，對照舊圖和無邊框圖的 Native AE 增益，才能檢查背景造成的測光差異；單看拍攝結果亮或暗不足以證明有固定曝光偏差。
