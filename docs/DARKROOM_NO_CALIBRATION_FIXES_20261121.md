# 不需重新採集樣本的 RAW／暗房修復（2026-11-21）

本次僅改**解碼後的互動式處理、快取、LUT 元資料、Color 行為**；**不重新校正感光元件**。提交目標為 `minmain`，保留 `main`、SD 卡上的所有 `*.cube`、DNG 與 F3Y/F3E；`display-gray.f3isp`、`display-gray-v2.f3curve` 及 `display-color.f3isp` 均保持不變。

## RAW 工作流程

- 原始 DNG/RAW10 保存、CRC、SD 原始檔不變。
- `ROLLxxxx.F3C` 及記憶體線性場景仍作為 **RAW 解析完成後、任何調色之前** 的快取。暗房「Gray original」與「Gray v2 (trial)」共用同一份 `display-gray.f3isp` 原始感光 ISP，因此前後切換**不再解碼 DNG**。在「Off」和有灰階 ISP 的狀態切換，仍須重新讀取 DNG／去馬賽克，因感光基礎校正不同。
- RAW 解碼後不再執行無作用的原生 YUV `camera_color` 檔案讀取；僅非 RAW 圖像保留此選項。
- 使用者按 `A` 預覽 RAW，從已快取的線性場景建立**2×2 均值下採樣、半寬半高**的暫存場景進行色彩處理。原始線性場景與檔案不變。上屏標示 `Fast preview`；其顆粒、重採樣、銳化細節可能與輸出不同。
- **按 `SELECT` 才用原始全解析度重新進行暗房處理並存 JPEG**。會檢查高品質預覽存在才寫檔；無法完成原尺寸渲染時不會把半解析度圖片當成最終作品。
- 調整「WB shift」時，下屏是色彩方向色塊；**上屏使用暫時配方渲染實際照片**，即時反映 Kelvin + R/B 偏移。按 `X` 還原、按 `A` 才套用。底部 19×19 色塊使用目前 Kelvin，計算一次 Kelvin 矩陣並快取，不再每幀做 361 次 CIE/Planck 積分。

## Color +100%

- 負向 Color（−100～0）保留以前的**線性 RGB 灰階化、近似保留線性亮度**。
- 正向 Color（0～+100）使用 **sRGB HSL lightness 保護**的飽和度增加，避免舊線性-Y 色域映射常因一個通道抵達黑/白端而完全吃掉飽和度增益。超出色域的 LUT 輸入仍採原安全方案，不允許 NaN 或非有限色彩寫入。
- 新 Color 會改變某些彩色像素的線性 Y 與感知亮度感受，這是有意的視覺調色行為；**不把 +100% 解釋為「所有像素色差倍增」**。已在極限飽和的純紅／藍等無法再增加色差；灰色不會憑空變彩色。感光元件偏色不能靠此功能修正。

## LUT 色彩空間

未附帶元資料的既有 `.cube` **仍按照原配方的 SRGB 等預設**，保護全部既有 SD LUT，不擅自猜測 LUT 是否 F-Log2C。

為了讓確實為其他空間製作的 LUT 被正確轉換，可在檔案開頭加入配對註解：

```text
# FILM3DS_INPUT FLOG2C
# FILM3DS_OUTPUT SRGB
LUT_3D_SIZE 17
...
```

- `INPUT` 支援 `SRGB`、`LINEAR_SRGB`、`REC709`、`FLOG2C`。
- `OUTPUT` 支援 `SRGB`、`LINEAR_SRGB`、`REC709`。
- 必須同時指定 INPUT/OUTPUT；未知值與尚未實作逆轉換的輸出 Log 拒絕載入，避免**靜默套錯**。
- 已載入的 `.cube` 在同一暗房工作階段快取，白平衡或 Color 調整不重新解析 LUT。換 LUT 才重新讀取；修改 SD 檔案後需重新啟動 Film3DS 才重新載入。

## 仍然需要彩色或暗場資料的項目（未更動）

- RAW 白平衡的**實際感光元件增益**、各照明色溫下的實測 neutral、感光元件 → 顯示色彩矩陣（CCM）。
- DNG 原有 `AsShotNeutral=(1,1,1)` 與通用 `ColorMatrix1` 尚無可靠原生參數可代換。
- `RAW calibration: Off` 仍是**未校準** RAW 預設：黑位 0、RGB 單位增益、單位 CCM，**不是等於相機原生 ISP 的「Original color」**。先前灰階估計 41–42 不能替代遮光暗場與 RGB 校準，故本次沒有改動它的定義。
- GPU/CPU 顆粒的實機合成方向與像素一致性仍需舊款 3DS 實機驗證；沒有把這次的 UI 快取優化宣稱為修好了所有渲染異常。

## 必須驗證

1. 同一張 DNG 連續調整 WB Shift：上屏應跟隨且按 X 還原，不應改變 DNG；底部色塊應反映選取的 Kelvin。
2. 同一張已解碼 DNG 於 `Gray original` / `Gray v2` 來回切換，檢查不重讀原始 DNG；`Off` 與 Gray 切換應重新套用感光底層 ISP。
3. `A` 預覽的快速輸出尺寸較小；`SELECT` 最終 JPEG 須由完整原始解析度渲染，`1:1`、`3:2`、`16:9` 各做一次。
4. 對比 Color 0、+100、−100：確認 +100 會讓一般低飽和色變鮮明、−100 灰階，不改變全灰像素。
5. 以已有的未標註 LUT 驗證相容性，另以標記好的 FLOG2C→SRGB LUT 測試；未知／缺一標記必須報錯，不能靜默套用。

以上可用現有 DNG 與合成測試圖完成；實際 CCM 與絕對色溫修正另待取樣。
