# 线性 RAW 中性区域白平衡

本轮提供显影核心 API 和只读主机命令。选取真实灰卡或已知中性色区域，计算可以直接
替换 `FilmRecipe.white_balance` 的色温／红／蓝偏移，不叠加当前白平衡，也不改写原始影像。
触屏选区、跨重启编辑会话和输出显示映射尚未接入。

```sh
build/filmctl neutral-wb romfs/rawqa/gray.F3S romfs/calibration/display-gray.f3isp 300 240 9 9
```

参数为 RAW 文件、明确的校准文件，以及全分辨率、未裁切、未旋转图像的 x、y、宽、高。
输入沿用 `film_frame_read` 支持的 RAW 容器；非 RAW 图像拒绝。输出一行 JSON：
`kelvin`、`red`、`blue`、`accepted`、`rejected`、`residual_stops`、`spread_stops`。
命令只读取文件，不保存配方、不生成 JPEG。程序调用者将成功结果替换到配方后，使用
现有场景显影和配方保存接口；底层接口为 `film_raw_scene_neutral`。

取样来自校准后的线性场景，处于创作白平衡、曝光、曲线、LUT 之前。既有传感器校准
的 WB／CCM 已经包含在场景内，返回值针对该场景进行额外校正，不回写传感器校准。
核心 API 可以明确指定线性 RGB 有效上下界；命令采用每通道 0.01～0.95。
这些界限不是传感器饱和标记。场景目前没有保留逐像素传感器裁切掩码，不能保证
识别经 CCM 后落回范围内的饱和像素；应主动避开过曝、黑位和镜面反光。

算法在选区内计算 R/G、B/G 的对数均值及离散程度，亮度不同但同色度的灰卡不会
因为明暗渐变而失效。非有限值、负值及界限外像素被剔除；至少需要 9 个有效像素和
75% 有效覆盖。任一颜色比值的总体标准差超过 0.15 stop 时拒绝，避免明显混色选区。
此检查不能识别均匀的有色物体，用户必须选择已知中性目标。

拟合搜索既有色温参数 0 或 1000～10000 K（100 K 步进），并求最近的整数红／蓝偏移
（-9～9）。目标是校正后两通道相对绿色的最大对数残差，超过 0.08 stop 返回
UNSUPPORTED；无效区域返回 INVALID。失败不发布部分参数，源场景始终不变。
这是受现有配方精度限制的中和拟合；多组参数可能近似等价，输出 Kelvin 不是实测
光源色温，也不代表缺少标定的传感器已具备准确色彩。

测试覆盖中性、偏暖、偏冷、亮度渐变、无效像素比例、越界、混色及控制范围不足，
将结果送回真实 RAW 显影检查中性输出，并验证主机命令读取实际灰阶原片时不改变原片或校准。
